## A. Core Technical Problems Addressed

The initial Phase 3C forensic quality audit identified three key technical limitations in the RAG copilot and decision recommendation subsystem:
1. **Lexical Feature Hashing Limitations:** The vector representation relied on L2-normalized 128-bin word feature hashing (`hash(word) % 128`) rather than learned dense semantic sentence embeddings, causing paraphrased natural language queries without exact keyword matches to experience cosine similarity score dilution below $0.35$ and trigger unwanted refusals.
2. **Provenance Disclosure Gap:** The seeded NDMA, FEMA, and WHO emergency knowledge guidelines lacked explicit metadata metadata tagging to clearly distinguish locally compiled summaries from original government publication text.
3. **LLM Provider Telemetry Absence:** The LLM provider abstraction did not explicitly record telemetry identifying whether responses were generated by a live external LLM (`REAL_LLM_OPENAI`) or the deterministic rule-based grounded fallback template (`DIRS_GROUNDED_FALLBACK`).

## C. Embedding & Retrieval Architecture (Before & After)

### Architecture Before Remediation
```
User Query 
  → 128-bin Lexical Feature Hashing (LocalEmbeddingModel)
  → Fixed 0.65 Cosine + 0.35 Keyword Overlap (HybridSearchRetriever)
  → Score Filtering (Threshold S_max >= 0.35)
```

### Architecture After Remediation
```
User Query 
  → GroundingValidator (Prompt-Injection Regex Defense)
  → EmbeddingProvider (SEMANTIC_TRANSFORMER / sentence-transformers MiniLM-L6-v2 OR LEXICAL_HASH fallback)
  → HybridSearchRetriever (0.70 Dense Cosine Similarity + 0.30 BM25 Keyword Overlap)
  → Hazard Domain Filtering (Disaster Type Match / GENERAL)
  → Incident Context Builder (Fetch live DB ORM state: Incident, Severity, Priority, Duplicates, Risk, Demand)
  → LLMProvider (Telemetry Tagging: REAL_LLM_OPENAI vs DIRS_GROUNDED_FALLBACK)
  → GroundingValidator (Threshold Validation: top_similarity >= 0.35)
  → Structured Grounded RAG JSON Response + Audit Trail Persistence
```

## J. Remaining Honest Limitations

1. **Un-contextualized Long Paraphrase Refusals:** When broad natural language queries are asked without an attached `incident_id`, cosine similarity scores occasionally hover slightly below the $0.35$ threshold, triggering controlled refusals. The system prioritizes safety by refusing rather than providing ungrounded advice.
2. **Curated Summary Scope:** Seeded knowledge documents represent high-level emergency guidelines (`CURATED_SUMMARY`). Full real-world deployment should ingest complete multi-page PDF publications using dedicated PDF extractors.
3. **Fallback Testing Environment:** Verification was conducted using the deterministic fallback provider (`DIRS_GROUNDED_FALLBACK`) because live commercial LLM credentials (OpenAI/Anthropic) were not configured in the test environment.
